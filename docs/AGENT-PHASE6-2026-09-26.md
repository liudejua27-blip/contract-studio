# 第六轮：材料依据、完整任务评估与运行预算

继续使用 Node + Pi SDK 和同一位负责律师。没有新增审批阶段或固定模型调用；规则更新到现有交易 Skill 5.6.0。新增能力均沿用当前任务、摘要确认和版本记录。

## 实现

1. **材料读取**：可选本地 OCR 读取扫描 PDF 的无文字页，记录页码和待核提示；数量、运行时间和本机并行受限，结束清理临时文件。文件分歧保留两侧原文与文件哈希，用户自然语言选择后消除待定分歧；引用失真、参考范本冒充事实或过期材料均不能通过来源校验。客户与律师共用的来源栏可查看原文依据。
2. **法律来源**：原 `read_legal_source` 工具可进一步读取已经检索到的官方网页并分页。新内容产生新来源 ID，历史引用保留；读取范围、截断和失败均有明确记录。接入协议参照 [Tavily Extract 官方文档](https://docs.tavily.com/documentation/api-reference/endpoint/extract)。提取网页不等于核实现行法律效力。
3. **完整起草任务评估**：运行多轮交流、摘要确认、起草、核验、Word 导出、只读问答和局部修改；保存合同、来源、每项自动检查和人工评审表。内置 5 个合成样本覆盖分次付款、名称留空、连续修改、材料分歧及核心诉求。样本已展开完整输入后取哈希，输出和运行配置也绑定哈希，评分不再只看模型是否返回 JSON。
4. **单任务预算**：模型请求前持久化预留，返回后结算；起草、核验、修复及网络重试共用预算。默认 50 万记账 Token、36 次模型调用、15 分钟处理窗口。未报告用量及崩溃调用保守扣除预留量，记录失败时停止新调用，手动重试不重置预算。管理员能查看合同当前任务的消耗与上限。

## 评估用法

- `npm run eval:tasks`：仅本地模型替身，默认不会访问真实模型或法律检索服务。输出到忽略目录 `.data/qa/task-eval-<时间>`，含 `run.json`、`review.json` 和各场景 Word。目录与文件使用私有权限，禁止提交带私人合同的数据。
- `node --env-file=.env.local --import tsx scripts/eval-tasks.ts --live`：显式使用配置的真实模型，会产生费用；本轮未执行。可设置 `CONTRACT_EVAL_CASES` 选择少量样本，或用 `CONTRACT_EVAL_DATASET` 指向同一 schema 的独立合成/脱敏样本集。
- 评审人对 `review.json` 填写姓名、逐项 `pass/fail/uncertain` 及理由，之后执行 `npm run eval:tasks -- --score <run.json> <review.json>`。只计算已有记录，不调用模型。修改输入、输出或运行内容后不能沿用旧评审哈希。
- 开发集与留出集分别计分。默认目标 95%，例如 20 个留出样本中 19 个通过可达标；未知或漏评不计通过。少量样本下离散计数可能要求全过，这不等于把目标改成 100%。替身结果永远不能标记真实质量达标。
- 内置样本是流程与评分工具的起始样例，且已用于开发，不能宣称是独立盲测集。正式质量评估仍需冻结独立样本，包含混合、多方、跨轮更正及专业争议，并由合适人员判断。这里评估到可交付律师的 Word 初稿；律师沟通和最终交付使用另外的服务器流程检查。

## 本地验证与边界

- 最终 `npm run check:release` 通过：288 项测试中 275 通过、13 项数据库测试按默认配置跳过、0 失败；类型检查、Node 发布构建及独立 worker 构建通过。
- 服务器完整检查运行最终构建的 Node + 独立 worker，使用临时数据库空间和 11 次本地模型替身调用。验证预算跨起草/核验落库、管理员用量查询及权限、原有上传材料—初稿—同一律师沟通修改—保存—交付；隔离测试空间随后清理。
- 完整任务回放 5/5 完成，23 次本地模型替身调用，含材料读取工具；每项自动检查通过。质量通过率明确为未知，未把替身结果计入 95% 目标。
- 针对性覆盖预算耗尽、未知用量、崩溃预留、存储失败、重试不清零，以及 SDK 历史压缩同样计入预算；覆盖 OCR 未配置/缺程序/忙碌/页数上限/临时文件清理、冲突原文与用户取舍、官方网页提取失败/分页/截断/引用留存。
- 浏览器检查通过：原有律师侧栏、桌面与移动预览、历史读取、保存失败恢复正常；在旧草稿旁显示本轮材料分歧及两侧出处，无未处理页面错误。检查中的首次保存 503 是刻意注入的恢复场景。修复了旧版本来源覆盖本轮新材料分歧的问题。
- 日志与合成产物位于忽略目录 `.data/qa/phase6-*`、`.data/qa/task-eval-1790416729832/`；不含真实客户材料。

本轮没有付费模型调用，没有 100 用户生成压力测试，没有部署。机器上尚未安装 Tesseract，OCR 的限制、失败回退与读取衔接使用替身验证；真实中文扫描件识别质量未验收。法律网页扩展也使用服务替身，尚未验证实际供应商返回及当前法律效力。任务预算限制后续调用，不是供应商账单的绝对费用封顶；法律检索服务费用另外计费。
