# 代码审计修复与验证（2026-09-26）

本轮完成前次审计的五项修复，没有改变同一律师持续沟通、完善、交付的业务流程。未部署，未调用付费模型，也没有进行 100 用户真实模型压测。

## 实现

1. **Word 预览隔离。** 文档在不执行脚本的独立 HTML 文档中转换并移除活动内容、事件属性与导航链接，再放入空 sandbox 权限的 iframe；CSP 禁止脚本、外部网络、嵌套页面、表单，关闭 DOCX altChunk 渲染。正文与可用嵌入图片仍可预览，链接显示为文字，原 Word 下载不变。预览不再直接进入主网站 DOM。
2. **编辑保存恢复。** 修改状态同步失败后，保存按钮先重试同步，成功才发送保存请求；失败时继续保留未保存状态。编辑器存在时也提供重新连接入口。没有通过清空错误来跳过服务端确认；无文字修改的保存和交付能力保留。
3. **删除依赖与失败隔离。** 先记录文件/会话清理引用，再依次删除编辑会话、审核记录、合同。每份合同使用独立事务，一份失败不回滚其他合同。部分失败时维护命令返回非零退出码；数据库错误日志保留脱敏错误码与约束名，不输出参数或正文。
4. **删除期限可恢复。** 实际截止时间为原删除截止时间与最近合同活动加 30 天中的较晚者。继续沟通/修改会顺延，界面显示实际日期；后续到期可以正常清理，无须手工取消再申请。
5. **历史按需加载。** 浏览器默认最近 50 条起草消息、每个律师沟通最近 50 条消息，提供更早消息入口；版本列表保留元数据，只预取当前版和最近送审源正文，旧正文按选择/对比读取。账号范围内 ETag 允许无变化刷新返回 304；权限每次重查，登出清除内存缓存，登出前尚未完成的读取不能回填缓存。Agent 内部仍读取完整消息和版本，不受界面分页截断。旧合同集合接口限最近 20 份，完整列表使用既有分页接口。

无需新增数据库字段或迁移。本轮没有运行真实用户合同的清理；清理功能仅在独立临时 schema 上验证。
