# 合同类型扩展（2026-09-21）

原目录包含 12 类参考，但仅 3 类具备完整对话起草规则。本轮将其余 9 类接入同一确认、核对、Word 导出和律师审核流程；仍仅部署 Sites，无外部 Queue。

| 新接入类型 | 必需的生意信息（双方名称之外） | 专项关注 |
| --- | --- | --- |
| 保密 | 交流目的、资料范围、谁向谁披露 | 例外、必要披露、返还及保护范围；不问价款 |
| 房屋租赁 | 地址范围、用途、租金周期、付款、租期、押金、水电物业 | 出租权、地方规定、维修与退租 |
| 设备租赁 | 清单、地点用途、租金周期、付款、租期、押金、运输 | 现状、损耗、维修、安全 |
| 设计 | 范围、文件、用途、价款、付款、时间 | 源文件、字体图片及商标用途 |
| 摄影摄像 | 内容地点、成品、用途、价款、付款、时间 | 原片、肖像、音乐和场地 |
| 营销推广 | 平台工作、交付报告、服务费、付款、投放预算、时间 | 不虚构销量保底，分清服务费与预算 |
| 咨询 | 问题范围、成果、价款、付款、时间 | 可验收成果、资质和成功承诺 |
| SaaS | 软件套餐、账号容量、计价周期、付款、期间 | 数据、支持、导出与退出；不默认续费 |
| 事务委托 | 事务、允许操作、报酬、付款、办事费用、时间 | 权限边界、转委托与移交；拒绝泛化全权 |

租金和订阅费支持周期单价，不要求用户额外计算总额；付款检查不会把月租误认为整个租期总价。所有默认条款与用户事实分开，新增规则仍标记待律师专业审核。

## 验证与边界

扩展测试逐类覆盖收集、确认、结构核对、实际 DOCX 渲染及附件存在性；模拟模型用于隔离业务流程，不证明法律质量。另测 NDA 无需价款、周期租金与付款的区分。真实模型样本使用合成企业资料，结果单独保存至忽略的 `.data/expanded-types-live.json`。

适用范围与排除场景会直接提供给分类模型。遇到未覆盖类型先整理需求并转律师，不以一般服务绕过。规则仍依赖模型分类，尚未覆盖所有歧义、地区和特殊业务；没有真人律师审定证据。

本轮结果：61 项测试，57 通过、4 项数据库环境相关测试跳过。应用与托管端类型检查、两种生产构建、既有 Worker 业务回归通过。保密和房屋租赁真实模型样本完成分类、核对及 Word；营销样本初次出现日期校验误判和正文/附件核对问题，补充缩写日期解析、明确差异反馈及付款正文要求后，复测完成核对与 12551 字节 Word 导出（`.data/marketing-types-live.json`）。三项均为合成案例，不是真人律师审查。其余六类新增类型完成模拟模型与真实文档渲染验证，尚无逐类真实模型验收。
