# 通用合同质量升级

本轮增强适用于通用交易框架和所有既有专项类型，不以新建专项模板作为生成前提。沿用 pa1nrui1/legal-skills 的中国法律资料，增加应用层通用业务质量规则。

- 起草与审查都检查已确认事实覆盖、正文与附件实质完整性、履约与付款衔接、权利义务一致性。
- 核心范围或其他已知交易要素不能用以后确定来代替；允许新增、变更事项另行约定。不强制无偿、保密和持续合作具有价款、实物或验收条件。
- 已有事实但不足以起草时，通过 materialGaps 指定实质缺口及针对性业务问题，保留原事实，不重复询问整组信息；每轮最多三个问题。
- 模型把核心生意缺口仅放在律师备注时，工具要求其修正分类；法律审定意见仍交律师。
- 专业 reviewNotes 在质量检查后合并、随阶段状态和最终合同版本保存；一致性通过不等于律师审查完成。
- 对已确认且不常见的安排，不得强制改成模板偏好的条款；系统检查不得擅自新增日期、价款、付款比例或权利转让。

验证：83 项自动测试，79 通过、4 跳过；跨软件、采购、服务和通用合作检查空泛内容，同时允许正常的变更条款。验证了专业意见跨校验和导出阶段持久化。隔离 workerd 流程通过。真实模型咖啡机投放分成合作完成通用起草、检查和 Word 导出（约83秒）；开业活动服务在已知价款、日期和交付物时，仅追问活动工作范围。

边界：新增规则不是法律效力认证，也未对所有合同类型逐一做律师验收。实质缺项识别仍依赖模型，已通过上述用例，不保证零漏检。既有运行环境、双方法律交易范围、用户事实确认及真人律师流程保持。
