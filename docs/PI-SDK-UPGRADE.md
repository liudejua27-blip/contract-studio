# 完整 Pi SDK 本地升级

日期：2026-09-21。用户明确要求本轮只完成本地实现，暂不部署。

## 运行方式与边界

Node 应用现在使用官方 `@earendil-works/pi-coding-agent@0.86.1` 的
`createAgentSession`、`SessionManager`、`SettingsManager`、`ModelRuntime` 和
`DefaultResourceLoader`。不再由 Node 业务代码直接创建一个裸 `Agent` 处理每一阶段。
官方源码：https://github.com/earendil-works/pi/tree/main/packages/coding-agent

理解、起草、核验仍是业务检查点，但它们沿着同一合同的 Pi 会话继续。
并非持续占用内存的单例：请求之间释放对象，从 SDK 的持久化会话恢复。

- `npm run dev`：本地 Node 网站，完整 SDK。
- `npm run build:node` / `npm start`：Node 生产构建及本地运行，完整 SDK。
- `npm run build`：现有 Sites / Worker 兼容构建，**仍保留旧 Core 运行层**。
  构建会明确提示这一点；它不是完整 SDK 的部署产物。
- 线上 Sites 未变更。将网站接到独立 Node Agent 服务的远程接口、认证和部署切换尚未实现。

完整 SDK 的常规导入包含 Node、动态模块加载及桌面工具依赖。当前 Worker 的直接
打包及 Miniflare 装载探测未通过；没有通过伪造 Node 功能或裁剪上游源码来宣称兼容。

## 会话与上下文

- Node 的合同工作流经过所有者检查后，传入 ownerId、contractId、阶段请求 ID、
  原始聊天和当前交易台账。前端不能指定会话路径。
- `CONTRACT_PI_SESSION_DIR` 默认为 `.data/pi-sessions`。按所有者与合同 ID 的
  SHA-256 组合分目录保存 SDK JSONL；目录权限 0700，禁止静态公开、纳入 Git 或上传日志。
- 取消最近 24 条的 Node 截断。原始聊天去重导入，SDK 按 token 使用量压缩上下文。
- `find_transaction_history` 只访问当前授权合同的原始聊天，支持关键词和分页。
  压缩摘要不是事实证据，助手建议不是用户承诺。
- 每阶段重新注入当前交易台账及撤回规则；最新明确更正优先于旧草稿、旧工具结果和摘要。
- 采用进程间文件锁，避免同一合同同时写入。阶段结果按请求及输入摘要缓存，
  业务保存失败后重试可复用已校验结果。未完成调用保留审计分支，恢复时退回开始检查点，
  不把孤立工具调用传给下一轮。
- 工作流取消或租约失效会中止模型请求。进程崩溃后的残留文件锁需等待过期；
  默认约 5 分钟。普通重启和下一请求无需重新询问已有信息。

生产化部署需要持久磁盘。当前方案适用于单 Node 主机，不宣称多主机分布式锁、
关闭页面后的完整后台队列或跨机器会话复制已经完成。

## 工具、Skill 与模型

仅开放合同结果提交、合同规则读取、中国法律 Skill 读取、当前合同历史检索。
不开放 Pi 默认的 Bash、任意文件读写、代码执行；不加载宿主的个人凭据、全局扩展、
AGENTS 文件或项目自动发现资源。

继续使用已固定版本的 `pa1nrui1/legal-skills`。在系统提示保留平台适配规则及当前
阶段推荐参考路径，资料正文按需读取，减少每轮无差别注入。没有增加合同类型门槛，
没有接入北大法宝、企查查等外部服务。

保留现有兼容模型的流式传输适配器，SDK 负责会话、工具循环和上下文压缩。
工具选择改为 auto；普通文本未按结构提交时，在同一会话内最多补做一次结构整理。
思考内容只用于模型协议连续性，不投影到公开进度。当前默认在事实整理阶段关闭 DeepSeek 深度思考，起草和核验遵循提供商默认值；
`CONTRACT_AI_THINKING=off` / `enabled` 可显式覆盖。初次通用分成测试在事实整理阶段
超时，因而增加了这一阶段区分，并保留会话、来源核对及原文检索能力。
因此本次升级没有更换模型，也不能保证响应自动变快。

Node 每阶段默认预算 240 秒，可配置，最大 600 秒；工作流租约同步延长。
既有 Word 校验、确认摘要、版本冻结、律师审核入口继续约束交付。
SDK 完成工具调用不等于文件已经保存或已经送审。
