# 2026-09-23 服务器版生产准备修复

本次只修改本地代码，没有部署。按用户要求移除 Sites 兼容层，没有执行 100 用户压测或调用付费模型。

| 原问题 | 当前处理 |
| --- | --- |
| 默认产物与 Node 能力不一致 | 默认构建统一为 Node 网页、完整 Pi SDK worker、维护程序；删除 Sites 前后端、适配器、D1/Drizzle 迁移、托管清单、专用构建和 smoke。生产配置改为原生 JavaScript，运行不依赖 TypeScript 编译器。 |
| 并发登录绕过限流 | 数据库原子递增后按返回值判断准入；键按固定顺序锁定。成功登录保留来源公共计数，仅清身份记录。 |
| 无 Content-Length 绕过大小限制 | JSON、上传和 ONLYOFFICE 回调全部按读取的实际字节计数，超限取消读取，并限制读取时间。 |
| Sites 聚合历史记录 1.5 MB 上限 | Sites 存储路径删除；正式路径采用 PostgreSQL 分表保存消息、版本和审核，私有对象存储保存 Word。 |
| 退出后敏感重试原文残留 | 按账号隔离的临时存储、30 分钟有效期、定期过期清理、退出与会话失效清理、跨标签页注销和旧数据迁移清理；阻止退出前异步发送结果更新新账号页面。 |
| 发布回归与协议失配 | 新建 Node 发布门禁，构建真实产物后用本地模型/存储替身完成起草、送审、补充、上传和交付。 |
| 账号维护缺口 | 主动改密、管理员二次验证后签发一次性重置链接、SMTP 自助找回、邮箱验证、首次强制改密、密码更新后登录和重置令牌失效；补首个管理员引导。 |
| 备份恢复 | 数据库一致快照、Word/Pi/编辑器保存版本、哈希校验、空目标恢复、恢复后会话失效、每日备份模板及运维目标。 |
| 监控和运营 | 任务与模型用量统计、可配置费用估算及阈值、管理页、每分钟监控模板；审核分配、待补充、交付通知持久化。 |
| 生命周期与访问审计 | 可撤销的 30 天删除申请、离线到期清理、孤立文件与旧 Pi 会话清理、认证/用量/审计保留期限、受保护 API 访问审计。 |
