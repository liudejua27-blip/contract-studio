# 可靠性升级：第一批

本批针对检查报告的四组优先问题。

- 新输入递增需求版本；理解失败或取消后，旧摘要不能用于确认。确认同时检查必要字段和已知数值冲突。
- 总价、税费、开票分别确认，保持自然语言对话；数字抽取必须得到原话支持，检查分期合计、付款比例、有效日期和日期顺序，生成后继续语义复核。模板框架版本为 2026.09.20.4，仍待律师审定。
- 已开始的审核须由管理员说明原因后转交；保留历史文件，清除原交付状态，新律师接收、上传审阅版后才可交付。原律师权限随分配变更收回。
- 当前界面改用每页20条摘要、服务器标题搜索及独立详情加载；旧列表接口保留兼容，不用于当前界面。

## 验证

- 单元测试37通过，4个依赖数据库的测试跳过。两套类型检查及云构建通过。
- 云端隔离模拟17组通过，包含转交后权限与交付限制、101份新增合同后的旧合同检索、账户隔离。详见 cloud-smoke-results.json。
- 本地真实DeepSeek：信息不足追问→补充后完整摘要→确认→生成→复核→导出Word；下载文件哈希一致，正文无待补充和内部来源提示。理解约4秒和8秒、生成约10秒、复核约1秒；单次样例非性能承诺。
- 浏览器检查本地律师列表搜索、直接链接刷新和390px手机页面；待接收任务无法上传。
