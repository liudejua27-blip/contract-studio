# Sites 首版

采用现有 React 界面，Sites Worker 承接 API，D1 存储账号、会话和合同记录，R2 存储私有 DOCX。线上首版关闭 ONLYOFFICE，律师下载修改后上传，再确认交付。

本机 Next/PostgreSQL 版本继续保留；npm run build:node 可构建本机版本，npm run build 产生 Sites 产物。云端不复制本机账号、合同或文件；通过预配置凭据的首次登录初始化云端管理员，由管理员开通律师和客户账户，凭据只保存于被忽略的 .data 目录。DeepSeek 密钥仅配置在 Sites 的服务端秘密变量。

合同记录按一个聚合文档存于 D1，修改使用 revision 条件更新。慢模型调用和 R2 上传不持有事务；发生并发修改时更新失败，不能覆盖已送审版本或他人修改。上传对象先写入随机不可变键，元数据更新失败时尝试清理该对象。交付指向已保存版本，重新起草不覆盖交付文件。律师读取只包含当前分配审核及其相关版本。

云端保留应用账号体系。随机会话令牌仅在 HttpOnly/Secure/SameSite cookie 中传递，数据库只存其 SHA-256；停用账户立即清除会话。密码使用运行环境支持的 WebCrypto PBKDF2 SHA-256 100000 次和随机盐，登录有持久化限流；正式规模化上线仍需考虑密码恢复、身份服务及访问管理。站点外层另保持 Sites 仅所有者可访问策略。

限制：上传 DOCX 最大 10 MB，解压最大 24 MB；单份合同历史 JSON 最大 1.5 MB；列表最多返回最近 100 份。没有在线 Word 编辑、支付、签章或邮件通知。法律内容仍需专业律师审核。

验证：24 项既有单测、云端类型检查、生产产物生成，以及 scripts/cloud-smoke.mjs 的 12 组工作流检查。云端运行器测试使用模型替身验证处理链路，不作为 DeepSeek 线上调用证据；发布后另验收真实调用。
