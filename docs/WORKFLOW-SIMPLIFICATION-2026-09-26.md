# 合同服务流程精简

用户描述生意 → Agent 起草 → 用户提交核心诉求 → 同一位负责律师沟通与完善 → 律师交付成品。

- 律师确定后持续负责；移除转派入口及接口，初次分配和约定协助转正式合同时均保留原律师。
- 交付不依赖用户验收、样本审批或其他审核环节；交付页提供成品、说明和联系负责律师。
- 交付后继续在原合同中沟通，不新建审核任务，不改变已交付文件。新增消息通知对方。
- 律师需要了解的安排直接在沟通中询问，移除前台“请求补充”状态操作。
- 版本、文件保存和完整性保障保留。历史审核数据不迁移、不删除。
- 条款经验整理在版本页折叠为可选操作，内部偏好与样本管理不影响交付。
- 后续诉讼等法律服务可联系原律师另行沟通，本次没有实现诉讼委托、收费或代理承诺。

旧客户端的交付收件接口保留兼容；旧“发起新审核”请求返回提示，引导回到原沟通。
